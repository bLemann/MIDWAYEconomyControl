СЕРВЕР · АВТОЗАГРУЗКА ECONOMY OVERRIDE

Операций с сервером ещё не было

Используется FTP-профиль из вкладки «FTP / ФАЙЛЫ». Скачивание сохраняет локальную копию в data\server-files и сразу открывает документ в редакторе; выгрузка создаёт резервную копию .backup-метка на сервере и нехватающие папки. «Синхронизировать цены» скачивает текущий файл сервера и показывает его цены в таблице рядом с вашими (подчёркнуто «сервер: …»); рабочие правки не заменяются. В файле — базовые цены: живые цены после рандомизации SCUM наружу не отдаёт.

Передача конфигурации

Скачать выбранный файл можно из списка слева.

«Выгрузить документ» отправляет текущий документ как EconomyOverride.json в выбранную папку (существующий файл копируется в .backup, нехватающие папки создаются автоматически, после выгрузки показывается путь). «ТЕСТ ПОДКЛЮЧЕНИЯ» пошагово проверяет TCP, баннер, TLS, логин и папку. «Искать миниатюры» сканирует сервер до 4 уровней, находит файлы, названные по ItemID (например Weapon_AK47.png), и сохраняет их в data\icons — то же самое программа делает автоматически при запуске и импорте, если иконки отсутствуют и FTP-профиль сохранён. Загрузка файла: существующий файл сначала копируется в .backup-<метка времени>, новый файл создаётся без копии.

Добавить предмет торговцу

Товары, уже присутствующие у торговца — по ID или по названию, — не показываются в списке; только что добавленные исчезают сразу. Одноимённые варианты с другим ID можно раскрыть кнопкой под списком. Для стандартных торговцев список ограничен ассортиментом их роли в SCUM (Оружейник — оружие и патроны, Охотник — луки и ловушки, Рыболов — рыбалка и т.д.); ручной ввод ID ниже работает без ограничений. ID, которого нет в базе, добавляется со статусом UNVERIFIED — приложение не подтверждает его существование в игре. Окно остаётся открытым для добавления нескольких позиций.

Добавить товары по категориям

Для стандартных торговцев показаны только категории их ассортимента в SCUM (для нестандартных — все категории). Счётчики учитывают уже имеющиеся у торговца ID: будут добавлены только новые записи.
