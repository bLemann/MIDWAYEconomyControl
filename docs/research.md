# Результаты поиска аналогов и баз ID

Поиск выполнен через веб-запросы в рамках проекта. Факты, не подтверждённые напрямую, помечены «стоит проверить».

## Найденные аналоги
- **Scum Trader Configurator** — trader.scum-global.com: веб-редактор EconomyOverride, шеринг конфигураций через /share-ссылки. Ниша «офлайн-редактор на своей машине» при этом свободна (по обсуждениям на Reddit — «стоит проверить» актуальность).
- **SCUM Trader Tool** — github.com/scumworld/SCUM-Trader-Tool: десктопное приложение, интерфейсы EN/DE.
- **SCUM Easy Admin** — nexusmods.com/scum/mods/262: админ-инструмент со спавнером предметов (заявлено 2400+ ID).

Вывод: прямого аналога «локальный тёмный редактор экономики с каталогом и FTP-выгрузкой» поиск не выявил.

## Базы игровых ID
Найдены несколько источников, числа записей расходятся между собой:
- BetterScum — ~1477 ID.
- Ribbon Gaming — ~3236 ID.
- scum.wiki.gg, commands.gg, holy.gg — собственные таблицы.

Расхождение чисел означает, что ни одну базу нельзя считать эталонной без перекрёстной проверки — «стоит проверить».

## Попытки автоматического парсинга баз (не удались)
- scum.wiki.gg — transport error при загрузке.
- scum.fandom.com/wiki/Item_IDs — отдала только навигацию; подстраницы 403/404.

Следствие: каталог в проекте сделан сменным — стартовый items-db.json (образец: Оружие 6 ID, FlareCartridge, Egg; источники — скриншоты PANIKA и scum.fandom.com) заменяется файлом пользователя или дополняется импортом JSON/CSV через вкладку КАТАЛОГ.

## Инструмент PANIKA
Отдельный публичный инструмент «PANIKA» поиском не подтвердился — «стоит проверить». Референсы использованы только как дизайн-образец.
