# Roadmap MIDWAY Economy Control

## MVP — сделано
- Вариант A интерфейса (PANIKA-стиль) v0.2.0: карточки профилей, крупные табы, ИНСТРУМЕНТЫ слева, ТРЕЙДЕРЫ справа, таблица с фильтрами и шапкой торговца со счётчиками.
- Импорт EconomyOverride.json с нормализацией чужих форматов, редактирование правил экономики, экспорт и предпросмотр JSON.
- Модалка добавления предметов: категории, поиск, ручной ввод ID с UNVERIFIED, пакетное добавление, защита от дублей; пакетное «Добавить по категориям».
- Массовые операции: значения на трейдера/всех, сброс в -1, копирование списка, очистка, удаление трейдера, стандартные торговцы.
- Каталог: items-db.json (стартовый образец) + импорт сторонних баз (JSON merge / JSON-массив / CSV).
- Дифф «оригинал → текущий» перед выгрузкой + подсветка изменённых/добавленных строк прямо в таблице в реальном времени.
- Пресеты экономики (data\presets, save/load/delete) + экспорт/импорт пресетов файлами .preset.json для шаринга.
- FTPS Explicit: список, скачивание, загрузка с бэкапом.
- Оконный режим (pywebview) и автономный exe (PyInstaller ~43 MB) с иконкой и версией файла 0.2.0; пресеты в frozen-режиме пишутся рядом с exe.

## v1.1 — ближайшие шаги
- Доделка FTPS: обработка нестандартных сертификатов, понятные ошибки авторизации.
- Замена стартового items-db.json на полный дамп ID (см. docs/research.md).
- Выгрузка файлов/иконок предметов на тестовый сервер (ожидает данных подключения и формата иконок от пользователя).

## Ограничения проекта
- Только loopback; порт не выставлять в интернет.
- UNVERIFIED-записи не считать подтверждёнными игрой — проверять перед выгрузкой на сервер.
- Не помогать с обходом античита; правки только через официально документированные конфиги.
