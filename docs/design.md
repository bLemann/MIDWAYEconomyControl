# Дизайн MIDWAY Economy Control (вариант A, v0.2.0)

Основа: панель «PANIKA» из 5 референс-скриншотов (`image.png` … `image4.png` в корне проекта + скриншот с трёхколоночным раскладом). Решения зафиксированы в `web/index.html`, `web/style.css`, `web/app.js`.

## Топбар
- Слева — глитч-логотип «MIDWAY» (белый текст с красно-синей тенью) и подпись «CONFIGURATOR · TRADERS:».
- Карточки профилей: SCUM TRADER CONFIG EDITOR / EconomyOverride.json (активна, красная рамка с свечением), QUEST / LOOT / SKILL — disabled с пометкой скоро.
- «← ИМПОРТ ФАЙЛА» и флаг «● Есть изменения · N».

## Таббар
Крупные табы по центру: НАСТРОЙКИ / ПРЕДМЕТЫ / ВЫГРУЗКА; активный — красная заливка `--red: #df4148`. Справа маленькие служебные: КАТАЛОГ, FTP/ФАЙЛЫ, RCON, ИСТОРИЯ. Обзор-вкладка убрана как избыточная.

## ПРЕДМЕТЫ — три колонки (по референсу)
- **ИНСТРУМЕНТЫ (слева):** поля Покупка/Продажа/Дельта/Очки славы; «ПРИМЕНИТЬ ТЕКУЩЕМУ ТРЕЙДЕРУ» (красная), «ПРИМЕНИТЬ ВСЕМ ТРЕЙДЕРАМ», «СБРОСИТЬ ЗНАЧЕНИЯ В -1»; «СКОПИРОВАТЬ В…», «ОЧИСТИТЬ СПИСОК». Пустые поля пропускаются.
- **Центр:** панель фильтров (поиск по ID/имени + категория, зелёная «ДОБАВИТЬ», «ДОБАВИТЬ ТРЕЙДЕРА», «ДОБАВИТЬ ВСЕХ ТРЕЙДЕРОВ»), вторая строка («ДОБАВИТЬ ТОВАРЫ ПО КАТЕГОРИЯМ», красная «УДАЛИТЬ ТРЕЙДЕРА»); шапка торговца: имя, зелёный бейдж «СТАНДАРТНЫЙ ТОРГОВЕЦ», счётчики Всего предметов / Каталог / UNVERIFIED / Изменений; таблица: ПРЕДМЕТ (код + имя из каталога), КАТЕГОРИЯ, ПОКУПКА (красный), ПРОДАЖА (зелёный), ДЕЛЬТА, ОЧКИ СЛАВЫ, СТАТУС (БАЗА/UNVERIFIED), удаление.
- **ТРЕЙДЕРЫ (справа):** список с количеством строк, активный красный; фоновый водяной знак «MIDWAY».

## Стандартные торговцы
«ДОБАВИТЬ ВСЕХ ТРЕЙДЕРОВ» создаёт роли из референса: ОРУЖЕЙНИК, РЫБОЛОВ, МЕХАНИК, ГЛАВНЫЙ ТРЕЙДЕР, БАР, ГОСПИТАЛЬ, БАРБЕР, ОХОТНИК, MASTER HUNTER (пустые списки; роль — не гарантия, что сервер использует такой класс).

## Диалоги
- #add-dialog: категории слева, поиск, результаты, ручной ввод name/ID → дефолты '-1', UNVERIFIED вне базы, окно открыто для батча, дубликаты блокируются.
- #cats-dialog: чекбоксы категорий с количеством записей → пакетное добавление (дубли пропускаются).
- #copy-dialog: чекбоксы других торговцев → копирование списка (deep copy, дедуп по ID).
- #ask-dialog / #confirm-dialog: собственные input/confirm (window.prompt/confirm не используются — в webview их поведение ненадёжно).

## Каталог (вкладка КАТАЛОГ)
Объединение БАЗА (items-db.json) + custom[] (пользовательские записи, UNVERIFIED).
- Импорт JSON `{categories}` → merge в базу с дедупликацией по ID.
- Импорт JSON-массива или CSV (`name,id,category`) → custom-записи (UNVERIFIED).

## Настройки (правила экономики)
Generic-рендер всех не-traders ключей. Bool-подобные значения ('true','false','0','1') — крупные переключатели ВКЛЮЧЕНО/ВЫКЛЮЧЕНО; остальные — поля ввода. Кнопка «Применить в документ» вносит изменения.

## Выгрузка (вкладка ВЫГРУЗКА)
- ДИФФ «оригинал → текущий»: семантическое сравнение с базой (последний импорт/применённый JSON/пресет/скачивание) — по торговцам (+добавлено/−удалено/~изменено с разбивкой по полям) и ключам верхнего уровня; скачивание сбрасывает базу.
- **Дифф в таблице (реальное время):** строки сравниваются с оригиналом при каждом рендере — изменённые жёлтая подсветка (title со списком изменённых полей), добавленные зелёная; счётчики «изменено/добавлено» в шапке торговца; правка любого поля перерисовывает таблицу сразу.
- ПРЕСЕТЫ: сохранение/загрузка/удаление именованных снапшотов через /api/presets (файлы data\presets рядом с приложением); ЭКСПОРТ — файл `<имя>.preset.json` (формат midway-preset-v1) для шаринга; ИМПОРТ ПРЕСЕТА ФАЙЛОМ — принимает {name,doc} или сырой документ, добавляет в список.
- СКАЧАТЬ JSON — скачивание через blob.
- Живой предпросмотр документа (#json-preview).
- ПРИМЕНИТЬ ТЕХНИЧЕСКИЙ JSON (#json-import) — парсинг, нормализация и валидация через POST /api/economy/validate.

## Импорт чужих конфигов (normalizeImport)
Порядок распознавания: наш формат {"traders":…} → обёртки economy-override/economy/EconomyOverride/data → объект из массивов (ключ traders восстановлен) → массив объектов-торговцев (name/items и варианты регистров; ID из tradeable-code/TradeableCode/code/id/ClassName и др.; все значения приведены к строкам). Нераспознанное — понятная ошибка. Нормализация честно помечается в toast/log: «формат нормализован — проверьте ID».

## Backend-контракт
GET /api/health; GET /api/presets; POST /api/economy/validate, /api/presets/save|load|delete, /api/ftp/list, /api/ftp/download, /api/ftp/upload. 403 на cross-origin запросы, 413 на тела >8 MB. Пресеты — JSON-файлы в data\presets (frozen: рядом с exe), имена санитизируются. Сервер слушает только loopback.

## FTP-клиент (v0.2.1)
- connect_ftp: FTPS Explicit (AUTH TLS + PROT P) с одним повтором при обрыве рукопожатия; 5xx на AUTH/TLS или SSL/сетевые ошибки → откат на plain FTP (tls:false, интерфейс предупреждает); ошибка авторизации (530) проходит без ложных откатов; при неудаче обеих попыток — 502 со сводкой «TLS-… | Plain FTP: …». Вызов connect_ftp обёрнут в try — ошибки подключения всегда возвращаются JSON-ом.
- EPSV-фолбэк: если PASV-ответ сервера не парсится (битые хостинги/ALG), клиент автоматически пробует EPSV и использует порт из ответа.
- list: CWD в указанную папку; при 550 — откат к «/» (затем «.») с note в ответе; отдаёт path, tls, note, files (type/size/modified).
- Навигация в UI: папки помечены [ПАПКА], кнопки «Открыть»/«↑ НА УРОВЕНЬ ВЫШЕ», поле пути синхронизируется; скачивание/загрузка идут в текущую папку.
- Upload: если файл существует — сначала .backup-<метка>, потом замена; если файла нет — прямая загрузка (backupCreated:false). Подходит для выгрузки новых файлов (например, иконок).
- Локальная проверка контракта выполнялась против pyftpdlib (plain FTP + битый PASV): fallback пути, навигация, скачивание, загрузка нового и существующего файлов — все сценарии подтверждены.

## Оконный режим и exe
- `desktop.py`: HTTP-сервер в daemon-потоке + окно pywebview 1280x840 (min 980x600, фон #0d0f13); при закрытии окна сервер глушится.
- `app.py`: frozen-aware пути (`sys._MEIPASS` → WEB), `SERVER_PORT` глобал (используется origin-проверкой), `make_server(port=None)` с фолбэком на свободный порт (на части машин 8765 занят сторонней службой).
- Сборка `BUILD.bat` → `dist\MIDWAYEconomyControl.exe` (~43 MB), проверена: health OK, index 200, items-db.json отдаётся.
