# MIDWAY Economy Control

Локальный редактор экономики SCUM: правка `EconomyOverride.json` в графическом интерфейсе. Backend — Python standard library (HTTP-сервер + API), фронтенд — vanilla JS в `web/`, оконный режим — pywebview. Текущая версия: **0.4.1**.

## Возможности

- **Импорт конфигурации**: `EconomyOverride.json`, обёртки вида `{"economy-override": …}`, списки торговцев. Валидация на сервере приложения перед применением.
- **Редактирование строк торговцев**: `tradeable-code`, цены (`base-purchase-price` — покупка, `base-sell-price` — продажа), `delta-price` (множитель к базовой цене: итоговая = базовая × множитель), `required-famepoints` (слава), флаги `available-after-sale-only` (после продажи) и `can-be-purchased` (видимость: default — открыт, true — открыт явно, false — скрыт) через выпадающие контролы.
- **Массовые операции**: применение значений покупки/продажи/дельты/славы/флагов текущему трейдеру или всем выбранным (с пагинацией по секторам), сброс в -1, копирование списка в другие трейдеры, очистка списка, удаление трейдера, добавление стандартных торговцев 4 секторов (A_0, B_4, C_2, Z_3): Оружейник, Рыболов, Механик, Главный трейдер, Бар, Госпиталь, Барбер, Охотник, Master Hunter.
- **Каталог предметов** `web/items-db.json` (мета 1.1.0: 44 категории, 1256 предметов) с иконками: просмотр иконок в каталоге и таблице товаров, загрузка иконки файлом (до 2 МБ) или по URL, кэш в `data\icons`. Записи, добавленные вручную, маркируются `UNVERIFIED`.
- **Дифф «оригинал → текущий»** на вкладке ВЫГРУЗКА (по торговцам и полям) + подсветка изменённых (жёлтая) и добавленных (зелёная) строк в таблице в реальном времени. Предпросмотр итогового JSON, журнал сессии (ИСТОРИЯ).
- **Правила экономики** (верхний уровень документа): русские подписи, тумблеры true/false и текстовые поля.
- **Пресеты экономики** (`data\presets`): сохранение/загрузка/удаление, экспорт файлом `.preset.json` для шаринга и импорт такого файла.
- **FTPS Explicit**: навигация по папкам сервера, скачивание и загрузка. Существующий файл при загрузке сначала копируется в `.backup-<метка>`. Устойчивость: обрыв TLS-рукопожатия → повтор TLS → откат на plain FTP с пометкой; битый PASV → откат на EPSV; понятная сводка ошибок (включая 530 неверный пароль). Наблюдение за списком удалённых файлов (watch).
- **RCON** — экран-заготовка (протокол не подтверждён).

## Запуск

### Вариант 1: готовое приложение (exe)
Скачать `MIDWAYEconomyControl.exe` из раздела [Releases](https://github.com/bLemann/MIDWAYEconomyControl/releases/latest) (после локальной сборки готовый файл также лежит в `dist\`) — автономное оконное приложение, Python на машине не требуется.

- Требуется Edge WebView2 Runtime (предустановлен на Windows 10 20H2+ и Windows 11; при отсутствии — установить с сайта Microsoft).
- Отдельные антивирусы могут помечать PyInstaller onefile-сборку как подозрительную (false positive). Файл собран локально из этого проекта; при блокировке добавьте исключение или используйте вариант 2/3.

### Вариант 2: оконный режим (нужен Python)
Запустить `MIDWAY.bat` (эквивалент `python desktop.py`). Откроется отдельное окно приложения (pywebview), сервер работает в фоне.

- Требуется Python 3.10+ и зависимости: `pip install -r requirements.txt` (pywebview, pythonnet; Windows использует Edge WebView2).

### Вариант 3: браузерный режим
Запустить `start.bat` (эквивалент `python app.py`) и открыть напечатанный в консоли адрес, по умолчанию `http://127.0.0.1:8765`.

## Порт
Базовый порт — 8765. Если он занят, приложение автоматически подбирает свободный порт и печатает фактический адрес в консоли (кроме onefile-exe: там порт определяется динамически, окно приложения открывается само). Всегда ориентируйтесь на вывод запуска, а не на фиксированный URL.

## Каталог предметов (web/items-db.json)
Каталог, из которого заполняется модалка добавления предметов, хранится в `web/items-db.json`.

- Формат: `{"meta": {...}, "categories": [{"name": "...", "items": [{"id": "...", "name": "..."}]}]}`.
- Стартовая база — meta 1.1.0 (44 категории, 1256 предметов); её можно заменить своим файлом или дополнить прямо в интерфейсе (вкладка «КАТАЛОГ»): импорт JSON `{categories}` объединяется с базой (дедупликация по ID), JSON-массив или CSV (`name,id,category`) добавляется как пользовательские записи (хранятся в `data\custom-items.json`).
- Записи, отсутствующие в базе, маркируются `UNVERIFIED`: ID не считается подтверждённым игрой, перед выгрузкой на сервер проверьте его.

## Сборка exe (для разработки)
1. Установить Python 3.10+.
2. Запустить `BUILD.bat` (эквивалент: `pyinstaller --noconsole --onefile --clean --name MIDWAYEconomyControl --add-data "web;web" --collect-all webview --collect-all pythonnet --collect-all clr_loader --icon "assets\icon.ico" --version-file "assets\version.txt" desktop.py`).
3. Результат: `dist\MIDWAYEconomyControl.exe` (~43 МБ), версия файла 0.4.1.

Зависимости разработки: `requirements.txt` (pywebview, pythonnet, pyinstaller).

## Структура проекта
- `app.py` — HTTP-сервер и API: импорт/экспорт, валидация, иконки, FTPS, пресеты, подключения.
- `desktop.py` — оконная обёртка (pywebview).
- `web/` — фронтенд: `index.html`, `app.js`, `style.css`, база предметов `items-db.json`.
- `assets/` — иконка приложения и `version.txt` для сборки.
- `docs/` — `design.md`, `research.md`, `roadmap.md` (заметки проектирования).
- `data/` — создаётся при работе (не в репозитории): `presets`, `icons`, `server-files`, `connections.json`, `custom-items.json`.
- `EconomyOverride_updated.json` — пример целевой конфигурации.

## Безопасность
- Приложение привязано только к loopback-интерфейсу (`127.0.0.1`). Не выставляйте его порт в интернет.
- Пароли FTP/RCON не сохраняются в файлах проекта; галочка «Сохранить подключение» пишет их в локальный `data\connections.json` без шифрования — включайте только на своём компьютере.
- FTPS шифрует управляющий и файловый каналы TLS. Не вводите секреты на общедоступном компьютере.
- Приложение не изменяет файл на сервере напрямую: только выгрузка по FTPS с автоматическим бэкапом предыдущей версии.
