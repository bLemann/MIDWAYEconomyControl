# MIDWAY Economy Control

Локальный редактор экономики SCUM: правка `EconomyOverride.json` в графическом интерфейсе. Backend — Python standard library (HTTP-сервер + API), фронтенд — vanilla JS в `web/`, оконный режим — pywebview. Текущая версия: **0.6.2**.

## Что нового в 0.6.2
- **Исправлена ошибка FTP-списка** `[SSL: SHUTDOWN_WHILE_IN_INIT]` с FileZilla Server 1.x: на data-канал теперь переиспользуется TLS-сессия контрольного канала (session resumption; в Python 3.11 ftplib этого не делает), первая попытка — TLS 1.2, при сбое — автоматический повтор. «ТЕСТ ПОДКЛЮЧЕНИЯ» объясняет эту ситуацию понятным текстом.
- **Поиск файла на сервере** (вкладка «FTP / ФАЙЛЫ»): поиск по подстроке имени по всему дереву от выбранной папки (до 25 секунд, 60 результатов); у найденного файла кнопки «Открыть папку» и «Скачать».
- **Все иконки предметов встроены в exe** (~2457 шт. в `assets\icons.zip`): миниатюры в таблице и каталоге работают сразу после установки — без FTP-скана и ручной загрузки. Локальная иконка имеет приоритет; удаление встроенной иконки запоминается (маркер в `data\icons\__removed.json`), повторная загрузка её возвращает.
- **Обновление в один клик**: «ЗАПУСТИТЬ НОВУЮ ВЕРСИЮ» сама подменяет exe (старый файл переименовывается и удаляется автоматически), откат при сбое. Диалог «Что нового» открывается сразу после скачивания обновления; кнопка «ЧТО НОВОГО» и подсказка у «↻ ОБН» убраны.

## Что нового в 0.6.1
- **Каталог расширен до 2930 предметов (мета 1.2.0, 51 категория)**: база дополнена встроенным каталогом SCUM Admin Helper — новые категории «Транспорт — Запчасти», «Строительство», «Сельское хозяйство», «Оружие — Детали», «Оружие — Краски», «Одежда — Прочее», «Еда и напитки — Прочее». Подпись «нет в каталоге» в таблице товаров исчезает для подавляющего большинства ID.
- **Диалог «Добавить предмет»** показывает только то, чего ещё нет у выбранного торговца; только что добавленная позиция исчезает из списка, а когда категория добавлена целиком — выводится соответствующая подсказка.
- **Исправлен FTP-путь по умолчанию**: `/Server/SCUM/Saved/Config/WindowsServer` (старый `/SCUM/...` давал ошибку 550 и не даёт скачать экономику). Сохранённый старый путь мигрируется автоматически при запуске; «ТЕСТ ПОДКЛЮЧЕНИЯ» при ошибке CWD подсказывает стандартный путь.
- **Кнопка удаления строки всегда видна**: последний столбец таблицы товаров закреплён справа (sticky) — не уезжает за край при горизонтальной прокрутке.
- **~1800 иконок предметов** извлечены из ресурсов SCUM Admin Helper в `data\icons` (у локальной сборки; у новых пользователей миниатюры докачиваются с FTP или добавляются вручную).

## Что нового в 0.6.0
- **Автозагрузка иконок**: при запуске и после импорта программа сама проверяет, каких иконок не хватает, и при сохранённом FTP-профиле сканирует сервер, докачивая `ItemID.png` из папок иконок.
- **Локальная выгрузка JSON**: «СКАЧАТЬ JSON» сохраняет файл в папку `exports\` рядом с программой и показывает полный путь в уведомлении; кнопка «ОТКРЫТЬ ПАПКУ» открывает её в Проводнике.
- **ТЕСТ ПОДКЛЮЧЕНИЯ (FTP)**: пошаговая диагностика — TCP, баннер, AUTH TLS, логин, PROT P, папка — с понятными сообщениями вместо крипических SSL-ошибок. Клиент TLS не проверяет самоподписанные сертификаты игровых FTP.
- **↩ ОТМЕНИТЬ**: откат последних действий (до 50 шагов) — правки цен/флагов, добавление/удаление строк, масс-операции, копирование, импорт.
- **СИНХРОНИЗИРОВАТЬ ЦЕНЫ С СЕРВЕРА**: скачивает EconomyOverride.json с сервера, не заменяя рабочий документ, и показывает серверные цены в таблице («сервер: …», подсветка расхождений). В файле — базовые цены: живые цены после рандомизации SCUM наружу не отдаёт.

## Обновления
Программа автоматически проверяет новые релизы на GitHub (при запуске и каждые 30 минут; кнопка «↻ ОБН» — проверка вручную). При выходе новой версии показывается баннер: «СКАЧАТЬ» скачивает exe в папку `updates` рядом с программой (с проверкой размера и подсчётом SHA256) и открывает диалог «Что нового»; «ЗАПУСТИТЬ НОВУЮ ВЕРСИЮ» заменяет текущий exe новой версией, запускает её и удаляет старый файл (при сбое замены исходный exe восстанавливается).

## Возможности

- **Импорт конфигурации**: `EconomyOverride.json`, обёртки вида `{"economy-override": …}`, списки торговцев. Валидация на сервере приложения перед применением.
- **Редактирование строк торговцев**: `tradeable-code`, цены (`base-purchase-price` — покупка, `base-sell-price` — продажа), `delta-price` (множитель к базовой цене: итоговая = базовая × множитель), `required-famepoints` (слава), флаги `available-after-sale-only` (после продажи) и `can-be-purchased` (видимость: default — открыт, true — открыт явно, false — скрыт) через выпадающие контролы.
- **Массовые операции**: применение значений покупки/продажи/дельты/славы/флагов текущему трейдеру или всем выбранным (с пагинацией по секторам), сброс в -1, копирование списка в другие трейдеры, очистка списка, удаление трейдера, добавление стандартных торговцев 4 секторов (A_0, B_4, C_2, Z_3): Оружейник, Рыболов, Механик, Главный трейдер, Бар, Госпиталь, Барбер, Охотник, Master Hunter.
- **Каталог предметов** `web/items-db.json` (мета 1.2.0: 51 категория, 2930 предметов) с иконками: просмотр иконок в каталоге и таблице товаров, загрузка иконки файлом (до 2 МБ) или по URL, кэш в `data\icons`. Записи, добавленные вручную, маркируются `UNVERIFIED`.
- **Дифф «оригинал → текущий»** на вкладке ВЫГРУЗКА (по торговцам и полям) + подсветка изменённых (жёлтая) и добавленных (зелёная) строк в таблице в реальном времени. Предпросмотр итогового JSON, журнал сессии (ИСТОРИЯ).
- **Правила экономики** (верхний уровень документа): русские подписи, тумблеры true/false и текстовые поля.
- **Пресеты экономики** (`data\presets`): сохранение/загрузка/удаление, экспорт файлом `.preset.json` для шаринга и импорт такого файла.
- **FTPS Explicit**: навигация по папкам сервера, скачивание и загрузка. Существующий файл при загрузке сначала копируется в `.backup-<метка>`. Отсутствующие папки целевого пути создаются автоматически (mkdir по цепочке). Устойчивость: обрыв TLS-рукопожатия → повтор TLS → откат на plain FTP с пометкой; битый PASV → откат на EPSV; понятная сводка ошибок (включая 530 неверный пароль). Наблюдение за списком удалённых файлов (watch).
- **RCON** — экран-заготовка (протокол не подтверждён).

## Запуск

### Вариант 1: готовое приложение (exe)
Скачать `MIDWAYEconomyControl.exe` из раздела [Releases](https://github.com/bLemann/MIDWAYEconomyControl/releases/latest) (после локальной сборки готовый файл также лежит в `dist\`) — автономное оконное приложение, Python на машине не требуется.

- Требуется Edge WebView2 Runtime (предустановлен на Windows 10 20H2+ и Windows 11; при отсутствии — установить с сайта Microsoft).
- Отдельные антивирусы могут помечать PyInstaller onefile-сборку как подозрительную (false positive). Файл собран локально из этого проекта; при блокировке добавьте исключение или используйте вариант 2/3.

### Вариант 2: оконный режим (нужен Python)
Запустить `MIDWAY.bat` (эквивалент `python desktop.py`). Откроется отдельное окно приложения (pywebview), сервер работает в фоне.

- Требуется Python 3.10+ и зависимости: `pip install -r requirements.txt` (pywebview, pythonnet; Windows использует Edge WebView2).

### Вариант 3: браузерный режим
Запустить `start.bat` (эквивалент `python app.py`) и открыть напечатанный в консоли адрес, по умолчанию `http://127.0.0.1:8765`.

## Порт
Базовый порт — 8765. Если он занят, приложение автоматически подбирает свободный порт и печатает фактический адрес в консоли (кроме onefile-exe: там порт определяется динамически, окно приложения открывается само). Всегда ориентируйтесь на вывод запуска, а не на фиксированный URL.

## Каталог предметов (web/items-db.json)
Каталог, из которого заполняется модалка добавления предметов, хранится в `web/items-db.json`.

- Формат: `{"meta": {...}, "categories": [{"name": "...", "items": [{"id": "...", "name": "..."}]}]}`.
- Стартовая база — meta 1.1.0 (44 категории, 1256 предметов); её можно заменить своим файлом или дополнить прямо в интерфейсе (вкладка «КАТАЛОГ»): импорт JSON `{categories}` объединяется с базой (дедупликация по ID), JSON-массив или CSV (`name,id,category`) добавляется как пользовательские записи (хранятся в `data\custom-items.json`).
- Записи, отсутствующие в базе, маркируются `UNVERIFIED`: ID не считается подтверждённым игрой, перед выгрузкой на сервер проверьте его.

## Сборка exe (для разработки)
1. Установить Python 3.10+.
2. Собрать `assets\icons.zip` из `data\icons` (архив PNG-иконок в корне архива, без `__removed.json`).
3. Запустить `BUILD.bat` (эквивалент: `pyinstaller --noconsole --onefile --clean --name MIDWAYEconomyControl --add-data "web;web" --add-data "assets\icons.zip;assets" --collect-all webview --collect-all pythonnet --collect-all clr_loader --icon "assets\icon.ico" --version-file "assets\version.txt" desktop.py`).
4. Результат: `dist\MIDWAYEconomyControl.exe` (версия файла 0.6.2).

Зависимости разработки: `requirements.txt` (pywebview, pythonnet, pyinstaller).

## Структура проекта
- `app.py` — HTTP-сервер и API: импорт/экспорт, валидация, иконки, FTPS, пресеты, подключения.
- `desktop.py` — оконная обёртка (pywebview).
- `web/` — фронтенд: `index.html`, `app.js`, `style.css`, база предметов `items-db.json`.
- `assets/` — иконка приложения, `version.txt` для сборки, `icons.zip` (встроенный набор иконок).
- `docs/` — `design.md`, `research.md`, `roadmap.md` (заметки проектирования).
- `data/` — создаётся при работе (не в репозитории): `presets`, `icons`, `server-files`, `connections.json`, `custom-items.json`.
- `updates/` — скачанные обновления (создаётся автоматически при скачивании новой версии).
- `exports/` — JSON-выгрузки из кнопки «СКАЧАТЬ JSON» (создаётся автоматически).
- `EconomyOverride_updated.json` — пример целевой конфигурации.

## Безопасность
- Приложение привязано только к loopback-интерфейсу (`127.0.0.1`). Не выставляйте его порт в интернет.
- Пароли FTP/RCON не сохраняются в файлах проекта; галочка «Сохранить подключение» пишет их в локальный `data\connections.json` без шифрования — включайте только на своём компьютере.
- FTPS шифрует управляющий и файловый каналы TLS. Не вводите секреты на общедоступном компьютере.
- Приложение не изменяет файл на сервере напрямую: только выгрузка по FTPS с автоматическим бэкапом предыдущей версии.
